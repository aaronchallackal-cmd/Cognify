Educational Score Guides

How to understand your results

These broad categories are included for educational comparison only. They are not clinical standards or medical benchmarks.

Reaction Time Guide

Under 250 ms

Fast response during this short browser based task.

250 to 350 ms

Common range during many online visual reaction tasks.

350 to 500 ms

Slower response that may be influenced by several factors.

Over 500 ms

Delayed for this task, but not a medical result.

Why reaction time scores vary

Attention, fatigue, distraction, screen refresh rate, browser performance, input delay, and device performance can influence reaction time results.

About the Science

What the modules demonstrate

Reaction Time

Reaction time is the delay between a stimulus appearing and a person responding to it.

Selective Attention

Selective attention allows someone to focus on relevant information while ignoring distracting information.

Working Memory

Working memory temporarily holds information so it can be used during an immediate task.

Decision Speed

Choice reaction tasks require a person to identify a signal, select an appropriate response, and act.

Inhibitory Control

Inhibitory control helps suppress an automatic response when a different response is required.

Consistency

Comparing performance across multiple trials helps show whether responses remain stable or vary.

Responsible Use

Educational limitations

Cognify demonstrates cognitive science concepts through browser based tasks. It should not be used to diagnose, screen, or treat any medical condition.

Cognify is an educational cognitive performance demonstration. It is not a medical device and does not diagnose ADHD, concussion, neurological disease, or any health condition. Results should be interpreted as a short browser based performance snapshot, not a clinical assessment.
